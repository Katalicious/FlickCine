# FlickCine

O **FlickCine** é uma aplicação web inspirada no Tinder — mas, em vez de criar *matches* entre pessoas, cria *matches* entre **pessoas e filmes**.  
O utilizador faz login, vê filmes e séries obtidos da **API OMDb**, e faz “swipe” para indicar se gosta ou não.  
Com base nas preferências, o sistema cria uma **watchlist personalizada**.

---

## 🚀 Funcionalidades

- Login e registo de utilizadores (com SQLite)
- Ligação à API da OMDb (dados de filmes e séries)
- Interface de “swipe” (direita = gosto, esquerda = não gosto)
- Armazenamento local das preferências do utilizador
- Criação automática de uma **watchlist**
- Filmes rejeitados **não são recomendados novamente**
- Personalização simples com base nos “likes”
